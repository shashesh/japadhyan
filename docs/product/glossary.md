# Glossary

| Term                              | Meaning                                                                                                              |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Naam japam / nama japa**        | Repeated chanting of a divine name.                                                                                  |
| **Mantra**                        | A sacred sound, word or phrase used in repetition.                                                                   |
| **Sadhana**                       | Regular spiritual practice.                                                                                          |
| **Japa**                          | Repetition of a mantra or name, aloud, whispered or mental.                                                          |
| **Dhyana / dhyan**                | Meditation: steady, absorbed attention. The app's name, JapaDhyan, joins japa and dhyan.                             |
| **Mala**                          | A string of beads (usually 108) used to count japa. One pass is one _mala_ or _round_.                               |
| **Meru**                          | The larger "summit" bead of a mala, marking the end of a round.                                                      |
| **Manasika japa**                 | Silent, mental repetition.                                                                                           |
| **Namavali**                      | A list of a deity's names, each chanted once, usually as "Om … Namah". One full pass is one recitation.              |
| **Ashtottara Shatanamavali**      | The 108 names of a deity, e.g. the Vishnu Ashtottara. Often offered with a flower or kumkum for each name (archana). |
| **Sahasranama / Sahasranamavali** | The thousand names of a deity: as a hymn in verse (stotram), or as a list of names (namavali).                       |
| **Stotra**                        | A hymn of praise recited in order, e.g. an Ashtakam (8 verses) or the Hanuman Chalisa (40 verses).                   |
| **Paath**                         | One full recitation of a namavali or stotra, e.g. "11 paaths of the Hanuman Chalisa".                                |
| **Navadurga**                     | The nine forms of Durga worshipped on the nine nights of Navaratri, beginning with Shailaputri.                      |
| **Likhita japa**                  | Writing the name or mantra repeatedly.                                                                               |
| **Rama Koti**                     | A tradition of writing "Rama" one crore (10 million) times, often in notebooks offered at temples.                   |
| **Sankalpa**                      | A formal vow or intention, e.g. "108 malas in 40 days".                                                              |
| **Mandala**                       | A 40-day (sometimes 41/48-day) period of disciplined practice.                                                       |
| **Anushthana**                    | A large, rule-bound japa commitment, e.g. 24 lakh Gayatri.                                                           |
| **Diksha / guru mantra**          | A mantra received at initiation from a guru, traditionally kept private.                                             |
| **Brahma muhurta**                | The pre-dawn period (about 1.5 hours before sunrise) considered ideal for sadhana.                                   |
| **Panchang**                      | The Hindu calendar of tithis, festivals and auspicious times.                                                        |
| **Ekadashi, Pradosh**             | Recurring lunar observances, twice a month each.                                                                     |
| **Dakshina**                      | An offering or donation to a temple or teacher.                                                                      |
| **Lakh / crore**                  | 100,000 / 10,000,000.                                                                                                |
| **Naam Japna / Naam simran**      | Sikh practice of remembering God through repetition of the Name, e.g. "Waheguru". One of Guru Nanak's three pillars. |
| **Simarna**                       | Sikh prayer beads.                                                                                                   |
| **Nianfo**                        | Buddhist recitation of the Buddha's name, e.g. "Namo Amituofo".                                                      |
| **Navkar / Namokar Mantra**       | The central Jain mantra, recited in jaap.                                                                            |
| **Vikram Samvat / Nepal Sambat**  | Calendar systems used in Nepal and India.                                                                            |
