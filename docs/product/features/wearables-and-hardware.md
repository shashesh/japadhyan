# Wearables and hardware

Counting without looking at the phone.

| Feature                            | Phase | Effort | Notes                                                                                                                 |
| ---------------------------------- | ----- | ------ | --------------------------------------------------------------------------------------------------------------------- |
| Volume-button counting             | P1    | medium | Works with the phone in a pocket. Full support on Android; iOS restricts volume-button capture, so support is partial |
| Flip face down to pause            | P1    | easy   | Uses proximity / orientation sensors                                                                                  |
| Apple Watch app                    | P2    | medium | Tap to count, haptic per bead, stronger at meru; syncs to phone                                                       |
| Wear OS app                        | P2    | medium | Same as Apple Watch                                                                                                   |
| Bluetooth japa rings / smart malas | P4    | medium | Integrate existing digital tally rings; explore a partner-made smart mala                                             |

All hardware counts feed the same total — see [chanting-modes](chanting-modes.md#the-key-rule--one-count-many-inputs).
