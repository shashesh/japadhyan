# Store listing

## Why this form

- **Brand first, then what it is.** Store search matches the words in the name, and devotees search for "japa counter", "mala counter" and "japa mala", not for a brand they haven't heard of yet. The home screen shows only JapaDhyan, which fits without being cut off.
- **Same title on both stores**, so people recognise it.
- **Nothing either store rejects:** no emoji, no all caps, no "free", "no ads", "best" or "#1", no other apps' names ([Apple guideline 2.3.7](https://developer.apple.com/app-store/review/guidelines/#accurate-metadata), [Google Play metadata policy](https://support.google.com/googleplay/android-developer/answer/9898842)).
- **No repeated words.** Apple indexes the name, subtitle and keywords together, so the subtitle and keywords only add words the name doesn't have.
- **Only what ships.** The short description names P1 modes (mala, word by word, writing). Add voice when it ships in P2. Add Sikh, Buddhist and Jain terms (waheguru, simarna, nianfo, navkar) to the keywords when their content ships.

## Web

- **Site:** japadhyan.com, with japadhyan.app redirecting to it. Neither is registered yet.
- **App Store also needs** a support URL and a privacy policy URL: `japadhyan.com/support` and `japadhyan.com/privacy`.
