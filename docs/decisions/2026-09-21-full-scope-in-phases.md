# Keep the full scope, deliver in phases

## Context

The brainstorm produced many features: several chanting modes, voice counting, wearables, sankalpas, festivals, community, multi-faith support, partners.

## Decision

Keep **every** feature. Deliver them in four phases (see [roadmap](../product/roadmap.md)):

1. Launch — a complete daily practice
2. Deepen practice
3. Chant together
4. Every faith and the wider ecosystem

Each phase must ship something complete for the devotee.

## Consequences

- Hard features (voice counting, live rooms, handwriting) are scheduled after the easy modes are solid.
- Other faiths wait until P4 so each can be done with an advisor, but the P1 data model must accommodate them.
