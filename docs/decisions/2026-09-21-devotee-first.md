# Devotee-first, platform later

## Context

The app could be built first for individual devotees, or first as a platform for temples, ashrams and gurus (like the Sai app that inspired it, built for one organization).

## Decision

Build for **individual devotees first**. Temples, gurus and teachers join later as partners (Phase 4).

## Consequences

- The core loop (open → chant → offer → see progress) gets all early effort.
- No partner dashboards, white-labelling or multi-tenant content tools until P4.
- The data model should still allow partner-owned programs later.
